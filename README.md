# Hotel--Booking--System

🏨 Hotel Booking System – Frontend

A modern and responsive Hotel Booking System frontend website developed using HTML, CSS, and JavaScript. The project allows users to explore hotels, view room details, check booking information, and interact with a user-friendly booking interface.

📌 Project Overview

The Hotel Booking System is designed to provide a simple and attractive interface for hotel reservations.

Users can:

🏨 View available hotels and rooms
🛏️ Explore room details
📅 Select check-in and check-out dates
👥 Select number of guests
💰 View room prices
📝 Fill in booking details
📱 Use the website on different screen sizes
🛠️ Technologies Used

HTML5 – Website structure
CSS3 – Styling and responsive design
JavaScript – User interactions and booking functionality
